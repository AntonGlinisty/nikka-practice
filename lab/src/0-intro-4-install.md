## Компиляция и запуск тестов

Для запуска потребуется компилятор Rust и некоторые дополнительные утилиты.
Для удобства, их инсталляция записана в Makefile, поэтому можно просто запустить make в корневом каталоге Nikka.

```console
$ make install
$ make test
```

Она должна будет уставить rustup, компилятор, cargo и все требуемые утилиты.
После чего соберёт Nikka и запустит тесты.
Тесты ожидаемо упадут, так как задачи лабораторок ещё не выполнены.
