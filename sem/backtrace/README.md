# backtrace

Вам нужно научиться итерироваться по кадрам текущего стека и сохранять адреса возврата.
Реализуйте соответствующую функцию `backtrace()` в файле `src/lib.rs`.
Она должна вернуть список адресов возврата от самого вложенного стекового кадра наружу.

При итерировании по стековым кадрам нужно как-то понять, в какой момент останавливаться.
Можно опираться на то, что в тестах во внешнем стековом кадре гарантированно зануляется
ссылка на предыдущий стековый кадр.
